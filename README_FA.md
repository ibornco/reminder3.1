## نسخه 2.9 — پنل Store و مدیریت فروشگاه
- ورود پایدار به حساب Store و تشخیص نقش manager/staff از پاسخ سرور.
- پنل مدیر برای ساخت و غیرفعال‌کردن کارکنان، زمان‌بندی شیفت‌های تاریخ‌دار، ساخت/ویرایش/حذف وظایف عمومی و اختصاصی و ثبت محصول و سری‌های انقضا.
- پنل کارمند برای مشاهده برنامه شیفت و همکاران همان شیفت، وظایف عمومی مجاز و وظایف اختصاصی خودش.
- تکمیل وظیفه عمومی توسط کارکنان همان شیفت و نمایش آمار تکمیل برای مدیر.
- توکن ورود در SharedPreferences نگهداری می‌شود؛ خروج دستی یا لغو دسترسی باعث ورود مجدد می‌شود.
- داده‌های شخصی همچنان روی گوشی باقی می‌مانند و وارد API فروشگاه نمی‌شوند.

## نسخه 2.9.1 — اعلان، همگام‌سازی و مدیریت شیفت
- وضعیت اتصال همیشه در بالای پنل Store نمایش داده می‌شود؛ اینترنت قطع، مسیر VPN/سرور ناموجود و خطای سرور از هم تفکیک می‌شوند.
- عملیات فروشگاه در صف محلی نگه‌داری و پس از اتصال مجدد به‌ترتیب همگام می‌شوند؛ پاسخ‌های خواندنی نیز cache می‌شوند.
- بخش انقضا جست‌وجو و فیلتر دارد و تعداد Batch برای مدیر و پرسنل شیفت صبح/تمام‌روز قابل به‌روزرسانی است.
- تقویم ماهانه شیفت‌ها و نوع تمام‌روز اضافه شده است.
- WorkManager اعلان وظیفه جدید و انقضای محصول را در پس‌زمینه بررسی می‌کند؛ یادآوری مدیران ساعت 23:30 تنظیم می‌شود.
- آیکون اختصاصی برنامه و آیکون تک‌رنگ اعلان جایگزین شده‌اند و زمان انیمیشن جابه‌جایی کاهش یافته است.

**وضعیت ساخت:** APK در این محیط ساخته نشده است؛ Gradle و Android SDK موجود نیستند. Build در Codemagic و تست چندحسابی روی گوشی واقعی قبل از انتشار الزامی است. نسخه 3.0 در این اصلاحات تغییر نکرده است.
